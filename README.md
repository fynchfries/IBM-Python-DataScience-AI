# Python for Data Science and AI — Coursera

This repository documents my coursework as I study Python for Data Science and AI on Coursera. I am taking this course as part of my learning path toward earning a professional certificate in Data Science.

## Course Description

The course introduces Python programming skills used in data science and AI. Through lessons, Jupyter notebooks, and practice exercises, I am learning to write and run Python code, work with variables and common data types, use expressions and operators, and manipulate strings. These fundamentals provide a foundation for using Python in data-focused tasks and for continuing to more advanced data science topics.

## Repository Contents

- **`Module1/Lessons/`** — lesson notebooks and course exercises.
- **`Module1/Notes/`** — personal notes, summaries, and a Python cheatsheet.

This repository is a work in progress and will be updated as I continue through the course.
